XGC TRACKER — BUILD 3: EXPANDED TRIAL GUIDES

INSTALL
1. Extract this ZIP.
2. Replace index.html at your repository root with the enclosed file.
3. Keep .nojekyll (an empty copy is included).
4. Wait for deployment, then hard refresh with Ctrl+Shift+R.

No app.js, data.js, or styles.css is required. Old copies may remain: this page does not load them. All application styling, logic, and data are embedded in index.html. Open it directly for local preview.

CONTENTS AND CHANGES
- Original 18-weapon belt checklist.
- 30 relic entries with effects, prerequisites, and portal-opening summaries.
- Expanded trial objectives, rules, preparation, strategies, warnings, and verification notes in every relic entry.
- Dragon Egg has all six drafted trial stages.
- One shared completion disclaimer above the relic list, not repeated within every guide.
- Separate session-only checkboxes, filters and expanded panels for each mode.
- Map filtering, show remaining only, and mode-specific reset.

LIMITATIONS
This integrates the previously drafted guide text. It is not a new gameplay verification pass. Unconfirmed counts, timers, elemental matchups and source discrepancies remain marked. Some portal puzzles still need linked walkthroughs for exact item locations or puzzle cues. Do not present unresolved draft details as verified facts. The existing Warden 309 label is preserved with a discrepancy warning.

The application is manual, not connected to the game. Reloading resets progress. It does not make network requests except when a user opens an external reference link.

Browser smoke-test results are included in TEST-RESULTS.txt. Testing used headless Chromium, not the deployed GitHub Pages site.
